# Simulador Custodia de Expedientes (PWA)
Sitio estático: no necesita build ni servidor.
## Publicar en Vercel
1. Con GitHub: sube esta carpeta a un repositorio, entra a vercel.com → Add New → Project → importa el repo → Deploy (sin cambiar nada).
2. Con terminal: dentro de la carpeta ejecuta `npx vercel --prod`.
## Instalar como app en el celular
Abre la URL de Vercel en Chrome (Android) → menú ⋮ → "Instalar app"; en iPhone, Safari → Compartir → "Añadir a pantalla de inicio".
## Clave de Groq
Se pega en la pestaña IA y queda solo en el dispositivo (localStorage).
