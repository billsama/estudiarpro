# Simulador Custodia de Expedientes (PWA)
## Publicar en Vercel
1. GitHub: sube esta carpeta a un repositorio → vercel.com → Add New → Project → Deploy (sin cambiar nada).
2. Terminal: dentro de la carpeta ejecuta `npx vercel --prod`.
Vercel instala solo `pdf-parse` para la función `api/fuente.js` (lee normas oficiales de gob.pe y elperuano.pe).
## Instalar en el celular
Android: Chrome → ⋮ → Instalar app. iPhone: Safari → Compartir → Añadir a pantalla de inicio.
## Clave de Groq
Se pega en la pestaña IA y queda solo en el dispositivo.
